## 🚀 Projects

<details open>
<summary><b>🧩 Algo Playground — DSA Visualization Platform</b></summary>
<br/>

Learning Data Structures & Algorithms from text and static diagrams can be hard to follow — so I built **Algo Playground**, an interactive web app that turns DSA concepts into step-by-step visual animations. The goal was to make abstract topics like sorting, searching, and traversal actually *click* by watching them happen in real time, instead of just reading about them.

I built the entire interface in **React.js** with a strong focus on responsiveness and clarity, and used **Node.js, Express, and MongoDB** on the backend to manage content and user data. Each visualization is paired with a short, simple explanation so learners understand *why* the algorithm behaves the way it does, not just *what* it's doing.

**Tech Stack:** React.js · JavaScript · HTML5 · CSS3 · Node.js · Express.js · MongoDB

🔗 [View Repository](https://github.com/sahilmishra660)

</details>

<summary><b>📄 HireLens — Resume Screening Web App</b></summary>
<br/>

**HireLens** is a web application built to make the early stages of hiring faster for recruiters. Instead of manually going through every resume, recruiters can upload candidate resumes through a clean dashboard and evaluate them against a given job's requirements in one place.

I designed the entire frontend in **React.js** to keep the recruiter workflow simple and fast, while the backend — built with **Node.js, Express, and MongoDB** — handles resume storage, retrieval, and the evaluation logic. The project pushed me to think beyond just "building a UI" and actually design a tool around a real workflow problem.

**Tech Stack:** React.js · JavaScript · HTML5 · CSS3 · Node.js · Express.js · MongoDB

🔗 [View Repository](https://github.com/sahilmishra660)

</details>

<summary><b>🎓 Smart Attendance Management System</b></summary>

Attendance updates reflect in real time, and the whole system is built to be simple enough that anyone can use it without training — which was one of my main design goals.

**Tech Stack:** React.js · JavaScript · Node.js · Express.js · MongoDB
